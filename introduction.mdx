Mintlify is a documentation platform that turns MDX files in a GitHub repository into a fast, beautiful, fully hosted doc site — with no infrastructure to manage, no build pipeline to configure, and no design system to maintain from scratch. You write the content; Mintlify handles everything else.

## What you can build

Teams use Mintlify to ship product documentation, API references, internal knowledge bases, and developer guides. The platform is flexible enough for a two-person startup and robust enough for a large enterprise engineering org.

## How content is structured

A Mintlify project is a folder of MDX files plus a single `docs.json` configuration file. The JSON file defines your site's navigation, branding, and global settings. The MDX files contain your content. That's the entire mental model.

```text
my-docs/
├── docs.json          # site configuration
├── introduction.mdx   # this page
├── quickstart.mdx
└── guides/
    ├── authentication.mdx
    └── webhooks.mdx
```

<Note>
  You don't need a special folder structure — Mintlify reads the navigation paths you define in `docs.json` and serves the matching MDX files. Organize your files however makes sense for your team.
</Note>
